```text

Above-fold image     < 250 KB target
```

Rules:

- static rendering where appropriate
- optimize images
- always set image dimensions
- use responsive image sizes
- lazy-load below-fold media
- preload only the actual LCP asset
- self-host fonts through framework tooling
- load only needed weights
- avoid heavy UI libraries
- avoid social-feed embeds
- inspect the production bundle
